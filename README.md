# Anay Shivhare - Portfolio

React + Vite + React Router + Framer Motion.

## Run locally
    npm install
    npm run dev

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build
    npm run build

## Testing performance (Lighthouse)
Always test the production build, not the dev server (dev mode is unminified and scores much lower):

    npm run build
    npm run preview

Then run Lighthouse on the preview URL (usually http://localhost:4173).
